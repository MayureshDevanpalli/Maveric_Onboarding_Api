You are an expert in analyzing resumes and job descriptions.

Given a JSON object called ResumeData and a Job Description (JD):

1. Extract all relevant **skills from ResumeData**. These can be found in:
   - professional_summary
   - credits (all categories)
   - project_experience (tools and descriptions)
   - certifications
   - any other field mentioning skills
   Save them in the "resumeSkill" array.

2. Extract all relevant **skills from the JD**.
   Save them in the "requiredSkills" array.

3. Compare the skills in "resumeSkill" and "requiredSkills", and identify common/matching skills.
   Save the matching ones in the "matchedSkills" array.

Return the result as a JSON in the following format:

{
  "resumeSkill": [...],
  "requiredSkills": [...],
  "matchedSkills": [...]
}

Only return the JSON. No explanations or additional text.
